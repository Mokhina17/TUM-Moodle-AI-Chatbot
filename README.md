# TUM-Moodle-AI-Chatbot

The goal of this project will be to create a RAG enhanced Chatbot that students can use to reference the requirements of various courses.

The file (currently) contains:
- A requirements.txt file: This tracks libraries for use in our project keeping it clean and ensuring reproducibility for all collaborators.
- Source code files for the project: The project is largely going to be written using the Django framework.

To make contributions we will each create individual branches for various assigned tasks and when complete with a task merge them.
Code will need review before integration to ensure we do not run into serious merge conflicts or errors.

To make contributions clone the repository, create a new branch, version changes, commit and push them to the prerequisite branch.
